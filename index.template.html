Как подключиться

  1. Скопируйте ссылку подписки кнопкой выше.
  2. В Happ добавьте новую подписку из буфера обмена.
  3. Обновите список, выберите узел и проверьте подключение.

Проверка выполняется из GitHub Actions и не подтверждает доступность из сети вашего оператора. Публичные серверы могут отключаться или менять ключи.

Что здесь работает

Российские сервисы открываются напрямую. Домены .ru, .рф, .su, Яндекс, VK и российские IP идут без VPN в обоих профилях.

Сайт и подписки размещены на GitHub Pages. Запасная ссылка через Яндекс помогает получить файл подписки, но не переносит VPN-трафик через переводчик. Сборщик запускается каждый час. GitHub не передаёт ваш VPN-трафик: подключение идёт к выбранному публичному серверу.

Источники: независимые списки и публичные подписки автора исходного проекта. Личные конфигурации пользователя не публикуются.

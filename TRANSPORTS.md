# Туннели через сторонние сервисы: результат исследования

Проверено 26.10.2026. Ограничения пользователя: бесплатно, без VPS и без второго постоянно включённого устройства.

## Доставка подписки через Яндекс Переводчик

Пример LarpVPN: https://meowcat.me/vpn . Сайт прямо описывает ссылку translate.yandex.ru как способ обновлять подписку при белых списках. Прямая подписка и версия через переводчик при проверке вернули одинаковый JSON. Это способ получить конфигурацию, а не транспорт пользовательского VPN-трафика.

В нашей странице добавлена кнопка копирования запасной ссылки на happ.json через переводчик. Возможность загрузки через конкретного оператора и поведение переводчика могут меняться. Успешная загрузка подписки не означает, что указанные в ней серверы доступны.

## Автовыбор в LarpVPN

Два полезных профиля содержат observatory и routing.balancers со стратегией leastPing. В исследованной версии обычный пул содержит 16 узлов, whitelist-пул 7; проверки идут раз в минуту. fallbackTag указывает на первый узел соответствующего пула. Кроме этого подписка содержит отдельные узлы и информационные записи. Мы публикуем ровно два профиля, без таких дополнительных записей. Наш fallback закрывает подключение, если нет доступных узлов, и не отправляет весь трафик напрямую. Автовыбор относится к новым соединениям и не обеспечивает бесшовный перенос уже открытой TCP-сессии.

Исходные ключи LarpVPN не перенесены в наши источники: исследовалась архитектура по предоставленной пользователем ссылке.

Документация Xray: https://xtls.github.io/en/config/observatory.html и https://xtls.github.io/en/config/routing.html .

## Яндекс Документы: OpenFlux

Оригинал проекта: https://github.com/p1neappleXpress/OpenFlux . Изученный форк: https://github.com/ahgpeu/openflux . README описывает передачу TCP-пакетов через сообщения курсора Яндекс Документов, локальный SOCKS5 на клиенте и отдельную exit node. Для exit node нужны root и обычный доступ в интернет; README предупреждает о сбоях с новым редактором. Это не VLESS-ссылка, которую можно просто добавить в Happ. Без exit node не включено.

## Яндекс Телемост / VK / WB: whitelist-bypass

https://github.com/kulikov0/whitelist-bypass и https://github.com/kulikov0/whitelist-bypass/blob/main/docs/SETUP.md . WebRTC DataChannel или видеотрек между Creator и Joiner. Требуется Creator на стороне со свободным интернетом. GitHub Pages не заменяет Creator. При условии пользователя «без второго устройства» не включено.

## Yandex Cloud: yac-ws-bridge

https://github.com/noiseonwires/yac-ws-bridge/blob/main/README_RU.md . Использует Yandex Cloud API Gateway / функции и серверный адаптер; в некоторых вариантах ещё и клиентский helper. Нужны облачная инфраструктура и целевой сервер. Постоянный нулевой бюджет не гарантируется. Не включено.

Итого: сейчас применяется бесплатная доставка подписки через переводчик плюс обычные проверенные узлы. Туннели через Документы/звонки не объявляются работающими без реального выхода в интернет.
